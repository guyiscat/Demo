## 本版改动
- 修复快速连续按下/松开 A、D 后反复清零下落速度而悬停的问题。
- 初次按住朝墙方向仍可静止攀附，恢复冲刺。
- 攀附后松开方向键会进入缓慢下滑，约 0.28 秒的阻尼过渡，最终下滑速度 3.5 格/秒。
- 同一面墙松开后，快速重新按住不会清零下滑速度，也不会马上重新攀附；需真实离墙至少 0.12 秒或落地后才可重新攀附。换到另一面墙可正常攀附。
- 按向外方向会脱离慢滑，恢复空中移动与正常重力；空格仍可蹬墙跳。
- 斜向冲刺在碰到墙、顶面或地面时，结束整段冲刺，不继续保留沿墙分量滑行。之后普通重力或正常攀附规则继续生效。
- 检查点按 Checkpoint Id 的关卡顺序只向前更新；碰到旧编号或同编号时不改复活位置。重新开局才清空进度。
- 检查点高低不按当前 X 坐标临时判断，编辑地图时请给 Checkpoint Id 依路线递增的编号。
- 人物仍为 2×2 格；短跳 3 身位、长跳 5 身位、冲刺 5 身位，沿用上一版紧凑跳跃参数。

## 镜头问题与方案
旧镜头始终朝右偏两格，对每次小跳都跟随；缩放用每帧固定 Lerp 权重，帧率不同会导致过渡速度不同。

新版不增加 Cinemachine 等包，采用可在 Inspector 调整的独立 CameraMotion 算法：

|优化项|本版默认|作用|
|---|---|---|
|物理与镜头更新|Rigidbody 插值 + LateUpdate 读取 Transform|跟随渲染后的角色位置，减少物理帧与画面帧错位抖动|
|水平死区|0.8 格|角色小幅左右微动不会反复拖动整个画面|
|竖直死区|普通 1.5 格；贴墙 0.7 格|压制跳跃顶部和落地抖动，同时柔和跟随慢速下滑|
|横向平滑时间|0.18 秒|起步与停步有柔和过渡|
|纵向平滑时间|0.24 秒|上升、到顶点与落地时不立即抽动|
|朝向预留视野|最多 2.2 格，0.22 秒平滑|向前看，转向时慢慢改变，不瞬间从右切到左|
|速度预测|0.10 秒，上限 1.5 格|提前跟随跑动和冲刺方向，减小画面落后|
|冲刺追随|平滑时间 0.10 秒|高速移动时不拖着镜头跟不上|
|快速下落追随|纵向 0.13 秒；平滑提前看下方最多 1.3 格|更早看到落点，减少角色跑出画面|
|边界与取景|按镜头比例和地图尺寸计算；仅在接近视野边缘启用安全取景|兼顾角色可见与边界稳定|
|全图模式|位置和缩放均按秒数阻尼过渡，约 0.32 秒参数|不同帧率下使用相同的时间尺度|
|模式切换|清除旧跟随速度，不提前推进切换帧|降低低帧率模式切换时的跳变|
|复活|立即对准复活位置，重置速度与预留视野|避免从死亡点一路拉镜头到复活点|

数值是阻尼参数，不是规定所有情形必须在该时间内完成位移。
镜头不做屏幕像素取整：当前自由缩放下逐像素取整反而会产生小幅跳动。
普通游戏内按 Tab 切换全图。Unity 中选 Main Camera > Tuning 可继续调节。

### 如何按试玩反馈继续微调
- 跟随仍太慢：Horizontal Smooth 0.18 → 0.14；Vertical Smooth 0.24 → 0.20。
- 转向时晃动：Look Ahead Distance 2.2 → 1.6，或 Look Ahead Smooth 0.22 → 0.28。
- 跳跃画面上下动太多：Vertical Dead Zone 1.5 → 2.0。
- 慢滑时跟随不够近：Wall Vertical Dead Zone 0.7 → 0.4。
先改一组再试玩，避免同时变化导致无法判断原因。

## 验收
- 40 项原动作与尺寸、复活检查通过。
- 50 项新增试玩回归检查通过，含左右墙、1/3/10 个物理帧周期连续按松、极短松开捕获、慢滑速度、离墙再攀附、向上/向下斜冲撞左右墙、碰顶/落地结束冲刺、检查点不回退及镜头检查。
- 慢滑 1.2 秒下降约 3.257 格，最终速度接近 3.5 格/秒；10 ms 步长下最大速度变化约 0.0899 格/秒，未发生反复回零。
- 新镜头在测试路径相同时间采样中，30 对 120 帧最大偏差约 0.436 格，60 对 120 帧约 0.144 格；不是声称不同帧率逐帧完全相同。
- 站立微抖不会推动镜头；全图过渡可收敛；复活会清除旧镜头速度。
- Windows 独立程序另做墙面、冲刺、检查点、相机取景回归，动作高度/距离另做二次校准。
- 这组测试不等同于整张 Excel 地图全路线通关验证，镜头最终舒适度仍需要真人试玩判断。
