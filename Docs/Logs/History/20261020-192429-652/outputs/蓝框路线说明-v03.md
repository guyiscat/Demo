# 第一关 v0.3：按原图 40 个蓝框跑图

主目录：D:\UnityWallDashPrototype。
Unity 工程：Project，使用 Unity 6000.4.12f1，场景 Assets/Scenes/Level01.unity。

## 启动
- StartGame.cmd：自己试玩。
- WatchRoute.cmd：观看真实游戏中的按键回放，屏幕显示已通过蓝框数，绿色线显示实际移动轨迹。
- 回放结束后点击 PLAY YOURSELF 可手动试玩；REPLAY AGAIN 可重新播放；Tab 可切换全图与跟随镜头。
- 发给朋友时发送 FirstAscent-Windows.zip 并解压，保留 Play 文件夹全部内容。

## 操作
A / D 或左右方向键移动；Space / C 跳跃，贴墙时松开后再次按下可蹬墙跳。
Shift / X 配合方向键进行八方向冲刺，落地恢复一次冲刺。
没有按上攀爬；W / 上仅用于选择冲刺方向。
R 回检查点，Ctrl + R 重开，Esc 暂停，H 帮助，M 静音。

## 这次验收与上一版的区别
原图中从起点到终点之间的 40 个蓝框全部按顺序检查，不再只选其中一部分关键点。
蓝框位置直接来自 BlueprintMap.Route 的原图坐标，验收时没有另行移动目标位置。
每个蓝框要求角色中心相对该坐标在水平、垂直方向各不超过 8 原图像素。
回放只提供移动、跳跃、松开跳跃、冲刺输入；所有移动仍由正常角色控制器、重力与碰撞完成。
检查跳跃键的按下/松开边沿，不使用持续按住却反复产生 KeyDown 的输入。
正式连续回放只有起点初始化，不在途中传送、恢复冲刺或跳过尖刺判定。
独立审计器记录全部 40 个蓝框的位置、帧号、误差和每帧实际轨迹。

## 为按图跑通所作的修正
- 保留 v0.2 的图纸地形轮廓，未重排平台或改变蓝框坐标。
- 在开头窄缝第 7 个蓝框附近留出短段安全墙面，消除原先该接触位置的尖刺冲突。
- 蹬墙竖直初速度由 12.5 调为 14.5，空中转向加速度由 55 调为 100，匹配图中连续折返。
- 贴墙探测距离由 0.08 调为 0.16 单位，给予约数个像素的贴墙容差。
- 尖刺的危险碰撞三角形向内收至视觉三角形的 72%，保留可见轮廓，给予边缘容错。
- 没有开启无敌、飞行、自动攀爬或额外空中冲刺次数。
