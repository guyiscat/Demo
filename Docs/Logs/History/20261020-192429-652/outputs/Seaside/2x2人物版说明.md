# 海边白盒 · 2×2 人物版

本版把人物的外观和真实碰撞盒都改成 2×2 个 Excel 地图格，总共四格；人物内部有十字分隔以便辨认尺寸。
“一个身位”指完整人物的高度/宽度，即两格。

|动作|身位|地图格|
|---|---|---|
|空格短跳|3|6|
|空格长跳|5|10|
|鼠标左键朝光标冲刺|5|10|

跳高是角色中心从起跳点到最高点的上升距离；角色脚底也会上升相同距离。
冲刺按角色中心沿鼠标方向的直线位移计算，斜向总长度为 10 格，不是 X、Y 各移动 10 格。
提前碰到地形时正常阻挡，实际冲刺距离会缩短。

## 保存位置和启动

D:\SeasideWhitebox\StartGame.cmd：直接试玩。
D:\SeasideWhitebox\Project：Unity 工程，版本 6000.4.12f1。
打开 Assets/Scenes/Seaside01.unity 即可编辑地图。
新版试玩包为 SeasideWhitebox-Windows-2x2.zip，工程包为 SeasideWhitebox-Project-2x2.zip。
解压工程包后应选择直接包含 Assets、Packages 和 ProjectSettings 的目录，不能选择 Play 目录。

## 参数调整

Assets/Settings/Movement.asset 中 Short Jump Height=6、Long Jump Height=10、Dash Distance=10，单位均为地图格。
Body Side=2；实际 Player 的 Box Collider 2D Size 和 Sprite Renderer Size 都为 (2,2)。
保持原有移动速度和冲刺速度设置；这里调整的是尺寸及动作距离，并不自动改变整张地图的尺度。

## 验证范围

Docs/physics-tests.txt：真实 Unity 物理测量及检查点安全检查。
Docs/standalone-calibration.txt：独立 Windows 试玩程序的二次测量。
人物变大可能改变部分窄道的通过难度；本版没有擅自拓宽原地图，也没有声称整关蓝色路线已通关验证。
传送动作仍因缺少具体规则而未加入，仅保留重置状态。
