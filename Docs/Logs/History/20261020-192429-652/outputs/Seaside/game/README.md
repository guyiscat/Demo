# 海边地图 Excel 白盒

操作：A/D 左右；空格短跳 3 格，持续按住长跳 5 格；鼠标左键朝光标方向冲刺 5 格。
冲刺中提前遇到地形会被碰撞挡住，距离不超过 5 格。没有接触地形时只可冲刺一次。
贴近可攀附黑墙，按住朝墙方向的 A/D 静止攀附，不会自动上下攀爬；攀附恢复冲刺，空格可蹬墙跳。
黄色旗帜为检查点，碰到后死亡或 R 回此处；Ctrl+R 重开；Tab 全图；B 显示/隐藏蓝色轨迹；Esc 暂停；H 帮助。

## 启动与工程

双击 StartGame.cmd，或 Play/SeasideWhitebox.exe。
Unity Hub 添加 Project 文件夹，使用 6000.4.12f1 打开 Assets/Scenes/Seaside01.unity。
发送试玩包时发送完整 Play 文件夹，或 SeasideWhitebox-Windows.zip，不能只发 exe。

## 地图如何对应 Excel

工作表 Sheet1 的有色单元格范围 CG48:IE120，其中填色范围为 155 列 × 73 行。
每格对应一个逻辑地图像素，用 1 Unity 单位表示；像素图按整数格对齐，镜头缩放不改变格数。
世界坐标原点为 CG120 单元格左下角：X 从左向右、Y 从下向上。Excel 行号向下增长。
黑格是地形；红格是危险尖刺；黄色 2×2 组为检查点；蓝色 2×2 组仅为预想路线提示，不碰撞。
表格主题填充色被正确解析，黄色实际是 WPS 金黄色主题色的浅色变体。
右边红格拼成的 END 是文字标记，排除其危险判定；终点触发器位于最后的黑色平台上方。
蓝色轨迹是提示，不会把角色吸附到路径，也不等同于自动通关证明。

## 编辑地图

停止 Play 后，在 Hierarchy 展开 EXCEL MAP。
01 TERRAIN：按相邻同一行黑格合并的可拖地形条，名称保留 Excel 单元格地址。
02 SPIKES：每个红色地图格单独一个物体，可移动或删除。
03 CHECKPOINTS：每个黄色组单独一个父物体；子物体 Respawn 是复活坐标，拖父物体时一起移动。
04 BLUE ROUTE：蓝色参考轨迹，不参与物理碰撞。
顶部 Seaside > Map editing palette 打开拖放工具栏，可新增 Ground、Spike、Checkpoint 模块。
Assets/Prefabs 里的模块也可以直接拖进 Scene。W 移动、R 缩放、Ctrl 网格吸附、Ctrl+D 复制。
某段黑墙不允许攀附时，在该地块 Seaside Cell 的 Attachable 取消勾选。
Assets/Settings/Movement.asset 调整跳高、冲刺距离、滞空和下落加速度。
注意菜单中的重新导入会重建地图并覆盖场景中的手动修改，先备份。

## 动作细节与范围

短按定义为快速松开空格；持续按住至上升结束达到完整 5 格，途中松开可以得到中间高度。
松开空格会根据已上升高度压低剩余上升速度，跳跃缓冲和离地宽限辅助操作。
下落重力由轻到重过渡并设速度上限；冲刺结束消除残余竖直冲量，短暂滞空后重新渐进下落。
空白图案采用本地生成的像素地面、三角尖刺、旗帜和方形角色，不下载第三方素材。
传送尚无发动方式、目标、距离或规则说明；本版仅预留 TeleportReady 状态，在落地/攀附时重置，没有加入可发动的传送技能。
以本次明确要求为准，不沿用旧版持续攀爬、方向键冲刺或任意添加平台。
