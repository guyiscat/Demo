# 第一关 v0.2 修订说明

文件夹仍为 D:\UnityWallDashPrototype，双击 StartGame.cmd 试玩。
Unity 工程位于 Project，版本为 6000.4.12f1，场景为 Assets/Scenes/Level01.unity。
上一版保存在 Backups/v0.1，避免与新版混用。

## 按本次反馈修正
1. 完全删除按 W / 上方向持续攀爬的逻辑和相关参数。
2. 贴墙后再次按 Space / C 才会蹬离墙面；左右墙之间交替蹬跳获得高度。
3. 按住跳跃只影响跳跃高度，不会自动连续蹬跳；上方向仅用于选择冲刺方向。
4. 保留贴墙下滑和八方向冲刺；落地恢复冲刺，不再放置额外的冲刺补充菱形。
5. 角色改成与图中蓝框比例接近的正方形，避免上一版偏高的碰撞盒挤不进窄缝。

## 地图修正
本次根据原图的像素坐标逐点重建地形，而不是重新编排相似的障碍顺序。
- 起点地面、连续尖刺、两个小平台。
- 左侧带刺方块、其右侧窄缝和高低落差。
- 倒 L 形障碍及右侧带刺长墙。
- 中段高柱、左上方短墙与柱顶平台。
- 柱顶右侧带刺的狭窄下降通道。
- 右侧拱形折返通道及内部凸起。
- 终点前的低顶尖刺凹槽、右侧出口和 END 底座/箭头。

撤回了 v0.1 中额外增加的桥、休息台、补充点和检查点旗帜。
保留两个不改变地形的隐形检查点，分别在中段安全平台和柱顶。
蓝色空心方框与红色连线仅在 Tab 全图模式显示，用于对照原图，不是实体平台或额外角色。
手绘尖刺转换为三角形危险碰撞体，线条转换为直线和多边形轮廓。

## 操作
A / D 或左右方向键移动；Space / C 跳跃、再次按下可蹬墙跳。
Shift / X + 方向键八方向冲刺；R 回检查点；Ctrl + R 重开。
Tab 全图；H 操作说明；Esc 暂停；M 静音。

通过 Wall Dash 菜单从图纸重建地图会覆盖手动场景修改，请先备份。
