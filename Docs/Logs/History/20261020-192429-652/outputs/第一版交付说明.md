# First Ascent · 第一关白盒 v0.1

主文件夹：D:\UnityWallDashPrototype

## 直接试玩
双击 D:\UnityWallDashPrototype\Play\FirstAscent.exe。
如需发给朋友，请发送 Play 整个文件夹或 FirstAscent-Windows.zip，不能只发 exe。

## Unity 工程
在 Unity Hub 中添加 D:\UnityWallDashPrototype\Project，使用 Unity 6000.4.12f1 打开。
打开 Assets/Scenes/Level01.unity，点击 Play。
这是 Unity 2D 单人操作验证原型；“一起开发”通过共享工程协作，不包含在线多人玩法。

## 操作
- A / D 或左右方向键：移动。
- Space / C：跳跃；长按跳得更高，松开可短跳。
- Shift / X + 方向：八方向冲刺；无方向输入时向面朝方向冲刺。
- 贴墙时按 W / 上：向上爬；贴墙按跳跃键可蹬墙跳。
- 空中冲刺消耗一格；落地或接触青色菱形恢复。
- R：回到最近检查点；Ctrl + R：重开整关。
- Tab：切换全图；H：查看操作；Esc：暂停；M：静音。

## 对草图的理解与改动
保留从左下起点向高处爬升，再折返下降到右侧终点的方向和教学顺序。
草图的蓝色方块按角色经过的位置理解，不是每个位置都生成实体平台。
增加四个检查点和少量青色冲刺补充点，使新手可以逐段尝试。
平台比例和间距根据实际跳跃与冲刺能力调整，并非按图片像素描摹。
美术采用简单灰白几何白盒、青色角色/补充点、珊瑚红危险区域；不是最终美术。

## 修改和协作
- 在 Project/Assets/Settings/Movement.asset 调整速度、跳高、冲刺时长和爬墙速度。
- Level01 场景中的平台和尖刺可直接移动；每个对象都有明确名称。
- Wall Dash / Rebuild first level 会按 LevelFactory.cs 重建场景，覆盖手动场景改动，先备份。
- 共享 Assets、Packages、ProjectSettings 和所有 .meta；忽略 Library、Temp、Logs。
- 使用相同完整 Unity 版本，避免同时编辑同一个场景；本工程未自动创建远端仓库。
