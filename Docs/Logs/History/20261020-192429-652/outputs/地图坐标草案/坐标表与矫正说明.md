# 地图坐标草案 01 — 待你矫正，不修改游戏

本草案只读取你本次发送的图片，不复用上一版游戏地图坐标。黑线、尖刺和蓝框均以该图片为参考；手绘轮廓没有唯一精确边界，表中坐标是待确认的初始读数。

原点 O 在原图像素 (110,550)，位于起点左下方。X 向右、Y 向上；1 格 = 20 原图像素。此单位只用于沟通，暂不等同于 Unity 米。读数精度为 0.05 格，不代表手绘轮廓本身有该精度。

转换：X = (像素X - 110) / 20；Y = (550 - 像素Y) / 20。总图和所有局部图沿用同一原点。

B 为地形块；Bxx.Vnn 为该块拐点；S 为尖刺段；P 为蓝框路线点。表中的宽高是包围范围，不是把不规则地块改成长方形。开放折线不擅自加厚、补底或确定哪一侧为实体。

## 你可以这样修改

- “B05 整体向右 1 格，宽高不变。”
- “B06.V03 改到 (19,5)，B06.V04 的 Y 也改到 5。”
- “S03 从 Y=2.5 到 Y=5.5，中间 P07 接触处不留缺口。”
- “P19 是必须贴右墙的蹬跳点，P20 只要经过。”
- “B10 是顶壁，实体在上方，厚 0.5 格。”

先纠正地图结构和哪侧为实体，再决定尖刺安全缺口与蓝框操作含义；确认后再应用到 Unity。
