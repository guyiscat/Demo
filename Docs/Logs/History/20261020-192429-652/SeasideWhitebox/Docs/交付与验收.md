# 海边地图白盒 · Excel 新版

主目录：D:\SeasideWhitebox。旧白盒 D:\UnityWallDashPrototype 未修改。
Unity：6000.4.12f1；工程场景：Project/Assets/Scenes/Seaside01.unity。
运行：StartGame.cmd 或 Play/SeasideWhitebox.exe。

## 按最终要求实现

- A/D 左右移动。
- 空格动态跳跃：快速松开低跳，持续按住高跳，中途松开得到中间高度。
- 短跳目标 3 格，长跳目标 5 格。
- 鼠标左键朝光标方向冲刺，最终距离为 5 格（已按后续消息从 3 格修改）。
- 空中冲刺只使用一次；落地或按住 A/D 向可攀附墙面靠拢可恢复冲刺。
- 攀附完全静止，无上下攀爬，松开方向或向外移动则下落，空格可蹬墙跳。
- 冲刺后消除残余冲量，短暂滞空后逐渐加速下落，下落有速度上限。
- 红格尖刺、黄色检查点、蓝色非碰撞路线提示、死亡复活、终点与全图查看。

## 导入一致性

Sheet1：155×73 格；1619 个黑色地形格，224 个红色格，48 个黄色格，84 个蓝色格。
其中 35 个红格是最右侧 END 字样，仅作为标记，实际危险尖刺为 189 格。
48 个黄色格合并为 12 个相邻 2×2 检查点，84 个蓝色格合并为 21 组路线提示。
每格为一个逻辑地图像素，用 1 Unity 世界单位表示。镜头放大显示，不将屏幕像素与物理单位混为一谈。
导入快照在 Source/海边地图-导入快照.xlsx，逐格 JSON 在 Project/Assets/Resources/SeasideMap.json。
没有为了沿用旧测试而移动平台或添加原表不存在的休息台。

## 地图拖拽编辑

Seaside > Map editing palette 打开模块面板；Assets/Prefabs 也可直接拖入 Ground、Spike、Checkpoint。
现有地形按连续同一行的黑格合并成条，可在 Scene 中选中移动、缩放，名称保留单元格地址。
检查点父物体内的 Respawn 子物体是复活点，拖动父物体可同步移动；也可以单独拖 Respawn 选安全落点。
停止 Play 后编辑，Ctrl+S 保存。重新导入 Excel JSON 会重建场景并覆盖手动场景修改。
