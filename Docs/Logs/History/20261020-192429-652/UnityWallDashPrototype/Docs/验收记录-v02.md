## 对图纸的具体处理
以原始图片像素坐标描摹轮廓，统一比例为 26 px / Unity 单位。
手绘折线规整为直线和多边形；尖刺为有实际碰撞的三角形。
蓝框与红线为只在全图中显示的路线注释，不参与碰撞。
右上窄道的线条厚度按通行空间绘制，尖刺之间保留原图接触位置附近的安全缺口。
角色为 0.56 x 0.56 的方形碰撞盒；没有移动图纸通道来适应上一版偏高的角色。
