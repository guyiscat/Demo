## 当前游戏进度

已实现海边 Seaside 的 2D 平台跳跃原型。矿洞与森林目前只有地图原稿，本工程尚无对应可玩场景。

人物为 2×2 格，A/D 移动，空格短按跳4格、长按跳8格，鼠标左键朝指针方向冲刺8格。贴墙按朝墙方向可悬停并恢复冲刺，松开柔和慢滑，重新按向墙恢复悬停；空格蹬墙跳。平台土狼时间0.14秒，离墙宽限0.10秒，输入缓存0.12秒。没有自由二段跳。冲刺遇到地形停止整次冲刺，复活时清除残像。

检查点只能向后推进编号，旧检查点不会覆盖新的复活点。Tab 全图、B 蓝色路线、R 复活、Ctrl+R 重开、Esc 暂停、H 帮助。镜头使用已有的自定义死区和平滑跟随，残像采用对象复用。

历史日志明确说明：蓝线是视觉参考；动作距离缩短到4/8/8之后，没有完成人工全路线通关，不能把旧阶段路线验收或自动物理测试当作全图可达证明。

## 数据到场景

```text
maps/海边地图.xlsx
    ↓ 前期导入（本次没有重新导入或生成场景）
Project6.4/Assets/Resources/SeasideMap.json
    ↓ SeasideBuilder（会覆盖场景手动修改，慎用）
Project6.4/Assets/Scenes/Seaside01.unity
    ↓ PlaytestFixBuild.Build / Tools/BuildAndTest.ps1
Demo/Play64/SeasideWhitebox.exe
```

地图逻辑为155×73格，JSON保存1619个地形格、224个红格、48个检查点格、84个路线格；红格里包含终点旁的 END 文字，不能全部作为伤害尖刺统计。地形在场景中按每行连续格合并成可编辑条块；检查点与路线也按区域分组，因此场景对象数与 Excel 格数不同。

本次逐个核对 JSON 中的1975个来源格，其地址对应的海边 Excel 填充类型全部一致。Excel 还有地图导出区域之外的内容，因此整张表的填色总数不等于 JSON 格数。本次没有写回 Excel。

**已保存场景保留了后续手工编辑，应以场景中的真实 Collider、触发器与复活锚点为当前关卡依据。** 美术预览最初复制此场景，后续独立保存分层美术；当前层级见 [SceneHierarchy.md](SceneHierarchy.md)。
