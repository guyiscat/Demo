## 这次修改

1. 紧靠可攀附墙时，按住朝墙方向的 A/D 悬停；松开后平滑慢滑；再次按住朝墙方向即可重新悬停，不需要先离墙或落地。
2. 重新松开会重新柔和进入下滑。慢滑上限 3.5 格/秒，平滑时间 0.28 秒；按离墙方向则脱离墙壁正常下落。空格仍然蹬墙跳，不会上下攀爬。
3. 平台土狼时间由 0.10 秒调至 0.14 秒：走出平台后短时间内仍能起跳，不是二段跳。追加修复另提供 0.10 秒离墙跳跃宽限，使用一次即消耗。
4. 保留并验证 0.12 秒落地跳跃缓存：提前按下空格，若在窗口内接触地面则立即起跳，过期不会自动起跳。
5. 过滤向上运动时的近地探测；起跳消耗跳跃资格，离开地面后再真实落地才恢复。冲刺和墙上悬停清除地面土狼资格，防止空中连续按跳跃产生额外起跳。
