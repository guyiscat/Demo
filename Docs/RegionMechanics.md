# 2026-11-27 区域机制与存档点修订

## 矿洞通路与照明

村庄跳进坑洞后仍有原1.5秒黑屏，但矿洞入场改为沿竖井X=86从上方向下落入，不再从屏幕左侧横移。矿洞起始区域向上跳入竖井上方出口即可回村庄坑洞旁；向下进入时不会误触返回。深井上端原有E返回标志继续保留。各方向转换均经过黑屏。

矿洞底部比特币用金色脉动光点显示，取得后光点消失，原E交互/阅读/取得道具的流程保持。鼠标照明在矿洞内自动启用，跟随鼠标位置；角色周围原可见圈继续保留，其他场景没有鼠标照明。它是可视遮罩，不是需要拾取/开关的手电，也没有新增按键。

调整矿洞Systems/MainCamera的MineDarkness：可见圆半径/边缘羽化控制角色照明，启用鼠标照明/鼠标照明半径/鼠标照明羽化控制鼠标光圈。新鼠标默认半径4、羽化1世界单位；原角色照明参数保留用户值。矿洞进入时GameSession由MineLevel自动安装MinePassage，运行中可查看上方出口及下落参数。

## 核心、防寒隔热与攀岩

获得矿洞比特币后，回到村庄机器人旁按E，读完获得核心对话，才启用S键防寒/隔热切换及相应地形/滑索保护、攀岩补跳。只取得比特币尚未交谈不算获得核心。未获核心接触冷热属性地形仍受伤；从编辑器直接进入雪山也不会自动发核心。

死亡、R复活和区域往返保留选中的冷热模式，不再固定变回防寒。核心与模式写入F5手动快照，继续恢复该快照；尚未保存的新核心不覆盖旧手动档。旧手动档没有核心字段时视为尚未获得，需回村庄交谈领取。

攀岩点由圆圈改为矩形判定与矩形边框。X/Y半范围为角色碰撞体半宽/半高再加Climb Padding，默认外扩0.5；所以当前雪山1×2碰撞体对应宽2、高3世界单位。角色在匹配模式的矩形范围内，每次重新按空格都可补跳，并恢复冲刺和传送；不再限制同一点一次。按住空格不会逐帧自动连跳。隔墙、离开范围或模式不符不能借点补跳。

设置资源Assets/Settings/Snow或Lighthouse的Climb Padding可调整矩形外扩距离；旧Climb Radius字段隐藏且不参与新判定。灰色不可攀爬墙面现在同时禁止贴墙、沿墙滑和蹬墙跳，也不能靠它刷新墙跳宽限时间。踩在灰色平台顶部的普通地面跳跃仍可用。

## 灯塔和结局

雪山残章选择继续并读完“这个东西也许还有用。”后解锁灯塔，有两条路：海边最左侧步行出口，或靠近海边lighthouse对象按E直接进入灯塔。两条路均使用相同黑屏转场。未解锁时不能进入灯塔，海边首次两页原剧情保持。灯塔美术Collider关闭时仍可按其形状范围交互，无需把碰撞重新打开。

雪山选择“留下/放弃”后，不再停在通关面板，直接淡出黑屏并返回主开始页。黑屏结束前菜单输入被锁定。最后一个F5手动存档保留，玩家可继续该存档。

## 自动复活点与教程

所有自动复活点的图片及子对象文字从游戏初始化起隐藏，触发Collider仍有效，不影响R/死亡复活，也不会覆盖F5手动档。灯塔坍塌等系统重置后也保持隐藏。

本轮初检47个复活点，其中31个带风险标记（含重复编号组内的所有成员）；处理中用户又新增一个灯塔复活点，该点也一起修复；最终共48个，实际重新分配14个重复编号、调整17个复活锚点。海边部分锚点原在地面上方约4单位，另有海边1处、矿洞1处、雪山2处与实体重叠。改为附近可完整支撑角色的中立固定地面，保留触发点位置、地图地形与原美术。新编号是标识，不代表关卡行进顺序。

初检、每项调整和复查分别见checkpoint-audit-before.txt、checkpoint-repairs.txt、checkpoint-audit.txt，均在[当前交接与验证](Handoff.md)。修复后静态复查为48/48通过；运行复活检查结果以工作日志和验证报告为准。用户处理中保存的灯塔场景通过按组件合并保留，没有整场景覆盖回旧版本。
