帮助里按 H、Esc 或“返回游戏”关闭。从暂停菜单进入帮助，关闭后回到暂停菜单。通过鼠标或键盘关闭菜单、结束对话等操作不会触发角色冲刺、传送或跳跃；按住的界面操作键要先松开，才恢复对应游戏输入。

## 游戏设置

- **游戏操作**：点击按键框，再按新的键盘按键或鼠标按钮；Esc 取消当前改键。支持左右移动、跳跃、交互、冲刺、传送、滑索、防寒/隔热及暂停。重复按键会与原动作交换，游戏内操作提示同步更新。
- **显示与声音**：拖动亮度、声音滑块即时生效，保留全屏开关。亮度作用于游戏摄像机画面，避免影响文字和黑屏转场。50% 为原始亮度。
- **重置设置**：只重置当前页。操作页恢复默认按键，显示声音页恢复亮度 50%、主音量 100%；保留全屏选择。
- **返回游戏 / Esc**：返回进入设置前的菜单。暂停菜单打开设置后，返回时仍保持暂停。

F5 存档、R 复活、Ctrl+R 重开、H 帮助、B 路线、Tab 镜头以及剧情数字选项仍是固定快捷键，不能分配给其他动作。设置保存在本机 PlayerPrefs，独立于每个进度槽位。

## 保存与读取

共 **5 个存档槽位**，采用新增“存档界面.jpg”的蓝色背景与居中放大卡片布局。每个有效卡片显示区域、保存时间、游玩时间和死亡数；从界面保存时额外生成游戏画面预览图。

1. 站稳在安全固定地面，按 **F5**，或 **Esc → 保存游戏**。
2. 点击目标卡片，或用上下 / W、S 选择，将目标放到中间；点击“保存至此槽位”，或 Enter 确认。
3. 空槽直接保存，已有文件的槽位会先询问覆盖。Esc 或“返回”取消选择。
4. 开始页选 **继续游戏**，在同一界面选档并点击“读取此存档”。默认选中最近保存的有效档，可以改选任意其他有效档。
5. “清除存档”只删除选中的槽位，需确认；无效或损坏且无法恢复的槽位也可清除。空槽不可读取。

选档时游戏暂停并屏蔽角色操作；从暂停菜单进入后取消会返回暂停状态。开始新游戏保留所有旧档，只有玩家确认覆盖才会替换所选进度。自动复活点继续只管理本次游玩的复活位置，转场、死亡、结局和返回开始页不会写入手动档。

原手动档继续使用 **第 1 槽**，不搬移、不清空。每个槽分别保存准确坐标、区域、机关、剧情、探索、核心、冷热模式和统计。加载位置因后续改图不安全时，沿用入口回退保护。

## 文件与维护

主工程为 `Project6.4`。新增界面自动由公共脚本创建，所有现有关卡及菜单共用，无须逐场景挂载。

- 设置：`Assets/Scripts/GameSettingsScreen.cs`、`GameBindings.cs`、`DisplayBrightness.cs`。
- 存档界面：`Assets/Scripts/SaveSlotScreen.cs`；进度文件规则在 `CampaignFlow.cs` 的 `CampaignSave` 中。
- 美术：`Assets/Art/Resources/MenuUI/`；Resources 子目录使打包后也能直接加载 Texture2D。原始 JPG 保留在根 `Assets/`。扁平参考图中的示例文字已清除，以阿里巴巴普惠体实时绘制实际文字。
- 亮度材质：`Assets/Resources/UI/DisplayBrightness.mat`，Shader：`Assets/Art/DisplayBrightness.shader`。

存档位置为 `Application.persistentDataPath`。第 1 槽仍为 `campaign-save.json`；第 2–5 槽为 `campaign-save-slot-2.json` 至 `campaign-save-slot-5.json`。同名 `.png` 为可选预览图。每槽使用独立 `.tmp` 原子替换及 `.bak` 上一份完整备份，读取失败只在本槽恢复。确认清除时删除本槽主文件、`.bak`、`.tmp`、`.png`；`.previous` 留作本机恢复副本，不出现在继续菜单。存档不放入 Assets，也不随交付包或 Git 上传。

构建使用 `Tools/BuildAndTest.ps1 -StartupPage`，新增设置与选档回归、独立路径写入/跨进程读取。测试只使用日志目录内的测试存档，不覆盖玩家进度。过程、失败记录与实际验证结果见[当前交接与验证](Handoff.md)。
