# 森林美术、暂停界面与传送（2026-11-27）

完整试玩运行根目录 `statgame.cmd`。本次不重新生成地图，所有原有地形、危险碰撞和机关位置保留。

## 新暂停界面与回退

Esc 打开新增 suspend 素材对应的暂停页，主要按钮为“继续游戏 / 游戏选项 / 保存游戏”。鼠标悬停显示素材自带的高亮，支持上下或 W/S 选择、Enter 确认，Esc 返回游戏。底部保留操作帮助和返回开始页，保存仍进入五槽选择。

要恢复本次之前的暂停页，在 Project 选中 `Project6.4/Assets/Resources/GameSystems.asset`，取消 **使用新版 suspend 暂停界面（关闭可回退）**。关闭该项只切换暂停页，其余功能仍保留。再次勾选即可恢复新版。


## 传送点互传

在区域的传送标志旁按 E，选择已探索区域后，经过黑屏直接到达**目标区域的传送标志附近**。不再以地图起点作为区域菜单的落点，也不从屏幕边缘走入。

标志略悬空时，系统会选择标志交互范围内的安全固定地面。需要手动指定精确站立点时，在标志对象的 **Travel Point → Arrival Anchor** 绑定一个放在安全地面上方的空对象；该对象代表角色中心。不要把角色中心放入地面碰撞体。未绑定时自动寻找附近安全落点，标志本身无需移动。

这是传送菜单的规则。地图边缘行走、村庄跳入矿洞、矿洞上跳或返回标志返村，仍按对应的步行/竖井/村庄起点规则运行。灯塔仍需要雪山继续解锁，未探索区域不会凭空出现在菜单。

海边读完灯塔的原两页对话后，现在真正获得信标传送：默认鼠标右键发射，再按一次传送；信标到达尽头也会传送。死亡恢复传送次数，手动存档/跨区域返回会保留已获得状态。海边参数为 `Assets/Resources/SeasideTraversal.asset`，与其他区使用同一个传送实现。传送红色连线在各区都隐藏，信标和离开/到达动作保留。

## 攀岩点提前按跳

雪山和灯塔攀岩点新增两个参数，在 Project 的 `Assets/Settings/Snow.asset` 或 `Lighthouse.asset` 中修改：

| 参数 | 默认 | 作用 |
|---|---|---|
| 攀岩点提前按跳缓冲（秒） `climbJumpBuffer` | 0.15 | 提前按跳跃，短时间内进入匹配攀岩点范围时自动起跳 |
| 离开攀岩点跳跃宽限（秒） `climbCoyoteTime` | 0.15 | 刚离开匹配攀岩点范围后，仍允许短暂补跳 |

每次按键只产生一次起跳，留在范围内可以重新按键反复跳。仍需获得核心并匹配冷热属性；不能隔墙使用。死亡、切换模式、冲刺、传送、暂停和界面操作会清除相应缓存，不把过期按键留到之后触发。

过程与实际验证结果见[当前交接与验证](Handoff.md)。

区域传送界面现使用 transfer 美术，灯塔不参与区域传送；防护核心光效说明见 [区域传送与防护光效](TransferAndProtection.md)。
