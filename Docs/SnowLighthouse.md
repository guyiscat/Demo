# 雪山与灯塔独立白盒

主工程为Project6.4，Unity 6000.4.12f1。雪山场景Assets/Scenes/SnowWhitebox.unity，独立入口snow.cmd；灯塔场景Assets/Scenes/LighthouseWhitebox.unity，独立入口lighthouse.cmd。两关不接入启动页进度或互相跳转。公共运动、镜头、方向箭头、复活、深绿系统面板和阿里巴巴普惠体与前面三关一致，地图背景沿用白盒浅绿底色，未制作主题贴图。

## 来源与地图解释

只读参考maps/雪山地图.xlsx、maps/灯塔地图.xlsx、Assets/文案.pdf第5—7页及桌面maker games/demo/DEMO游戏策划案.pdf第1—3页。雪山238×165格，黑色地形12759、灰色181、尖刺1152、冷/热实体各12格，冷/热滑索4条/2条（85格/39格），冷/热攀岩点各6组。灯塔74×249格，黑色2133、灰色107、尖刺967、冷实体42格、热实体5格，冷/热滑索3条/6条（48格/101格），冷攀岩点5组、热攀岩点6组。每个格子是一世界单位，源Excel地址保留在地形、尖刺、属性表面、滑索和攀岩点组件中。

完整策划案明确了S切换防寒/隔热、属性地形和滑索需要对应防护、无碰撞踏板补跳并恢复冲刺/传送、外冷内热的雪山路线，以及灯塔随时间坍塌的限时终关。文案PDF明确残缺策划案原文及两种选择。独立测试默认角色已持有核心和传送，灯塔视为已交付《DEMO》，不要求先游玩村庄或矿洞。

两张表均无文字图例。结合完整策划案采用如下设计解释：黑色为可攀附实体、灰色为不可悬停实体、红色为尖刺；雪山青色及灯塔浅青色为冷属性，粉红色为热属性。冷/热连通区域中2×2的四格小块为无碰撞攀岩点；独立的一格高、五格以上长横条为滑索；其他沿地形边缘的条块为实体属性地形。蓝色2×2标记用于雪山入口/沿途复活点，灯塔底部蓝色标记为入口，顶部标记为灯台终点。雪山底部青绿色六格为残章交互。

上述颜色/形状对应是实现采用的设计解释，不是工作簿中的文字说明。开始时已询问用户完整策划案，后在文件资源管理器近期项目中发现并只读核对原案，按原案补齐属性滑索、补跳恢复能力及坍塌限时，未等待澄清停工。灯塔塔底至塔顶、E点亮灯台的交互与两句灯台文案是本轮新增设计，终点游戏结束来自完整策划案。

地图的实体/尖刺逐格保留原表位置。另在已有中立平台放置雪山山顶与折返段休整点、灯塔下/中/上层休整点，仅增加复活标记，不添加或填平原有地形。复活锚点均放在无尖刺、无属性伤害的静态落脚面。原有保存场景不会由构建流程重建，首次创建器遇到已有同名场景会拒绝覆盖。

## 操作与机制

- A/D移动，空格短跳/长跳和蹬墙，左键沿角色金色箭头冲刺。右键发射信标，再次右键手动传送；传送可打断冲刺，落点回退避免进入实体，沿用当前0.5秒滞空配置。
- S即时切换防寒/隔热，可在空中、冲刺和信标飞行中切换。匹配属性时可正常站立、贴墙、蹬墙或使用属性滑索；错误模式接触相应地形、W抓错属性滑索或乘索时切换错误模式，造成冻伤/灼伤死亡。尖刺始终致死。小方块攀岩点仅检查补跳资格，本身无实体或接触伤害。
- 属性滑索沿用W抓索、A/D实时换向、空格跳离、左键冲刺脱离、右键信标及端点0.18秒补跳窗口；匹配属性的滑索恢复冲刺和传送。滑速保留当前12单位/秒。
- 攀岩点显示范围环；对应模式下进入中心4单位内，且与点之间没有实体遮挡，空中再次按空格可补跳并恢复冲刺和传送。普通地面/墙面起跳优先；同一腾空过程中每个点只能触发一次，离开再进入同一圆环不会刷跳。落地/贴墙或复活后重置点的使用状态。
- E靠近目标交互；对话期间角色停止、不可切换模式。E/继续按钮推进，残章选择可点击按钮或按数字1/2。暂停时不推进对话或切换模式。
- R最近实际接触的复活点，Ctrl+R重开本关，Esc暂停，H帮助，Tab近景/全景，B显示/隐藏路线。

雪山从左下入口出发，经冷属性路线登顶，切换热属性后折返至下方残章。原文两页后选择“留下吧，我属于这个即将消失的世界”，显示留下结局；选择“不，还没有结束，一切都还来得及”，展示“这个东西也许还有用”，保留残章并完成本关探索，故事标记为继续。两种结果均可R重开；本轮不自动跳转下一关。

灯塔从塔底出发，利用中立落脚面、冷热实体、属性滑索与补跳点穿过中段折返通道并登上塔顶。离开每段复活锚点2单位后开始计时，8秒准备后坍塌线从锚点下方12单位以1.15单位/秒追赶，线下的地形、尖刺、滑索、攀岩点与检查点实际禁用，角色被追上或超过本段150秒即死亡。触发新休整点、死亡复活或重开时恢复道路、以安全复活点重置该段追赶，避免永久软锁。暂停、帮助和对话期间追赶停止。靠近塔顶灯台E交互，读完后灯台变为金色，显示灯塔终点结局。底部不能远程触发终点，重开恢复未点亮状态。

## 参数入口

|资源|可调整内容|
|---|---|
|Assets/Resources/GameSystems.asset|公共字体、镜头、复活、方向箭头、系统设置|
|Assets/Settings/Movement.asset|所有关卡原有移动/跳跃/冲刺参数，本轮保持|
|Assets/Settings/Snow.asset、Lighthouse.asset|初始防护、攀岩点有效半径4、交互距离3.5、地形接触容差0.06|
|Assets/Settings/SnowTraversal.asset、LighthouseTraversal.asset|传送距离10、信标速度、传送后滞空0.5秒及打断冲刺开关，创建时复制当前Forest配置|
|场景ClimbPoint组件|各点的冷/热要求、源Excel地址、范围环|
|场景ThermalSurface组件|各属性表面的冷/热要求和源Excel地址|
|场景ThermalZipline组件|各滑索的冷/热要求，旁侧ForestZipline保留端点和源Excel地址|
|灯塔Systems/RoadCollapse的LighthouseCollapse组件|准备8秒、追赶速度1.15、初始落后12单位、每段150秒限时|
|场景Checkpoint/RespawnAnchor|触发区域和安全复活坐标|

共享的ThermalSettings、ThermalSurface、ThermalZipline、ThermalTraversal、ClimbPoint、ThermalLevel、ThermalHUD等放在Scripts根目录。雪山专属SnowLevel/SnowHUD放在Scripts/snow，灯塔专属LighthouseLevel/LighthouseHUD/LighthouseCollapse放在Scripts/lighthouse；编辑器入口相应位于Editor/snow与Editor/lighthouse。共用ForestPlayer通过可选environment引用接入新机制，前三关未绑定此引用。
