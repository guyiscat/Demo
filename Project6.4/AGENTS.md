# 本项目后续开发约定

- 用户要求：每次工作、问题修复和优化，都必须在本版本对应文件夹中留下日志。
- 当前交付根目录是本 Project 文件夹的上一级；统一日志在 ../Docs/Logs/。
- 开始前备份会改动的工程文件和试玩文件，放入 ../Docs/Backups/日期-主题/；保留手动地图修改，禁止未经要求重新生成场景。
- 每次建立 ../Docs/Logs/Work/日期时间-主题/，记录用户需求、原因与复现、改动文件、参数、验证命令、实际结果、未完成事项和回滚位置；同时追加 ../Docs/CHANGELOG.md。
- 无法复现或验证时如实记录，不将计划或推断写成已完成。历史补记必须标明补记及信息来源。
- 构建和测试使用 Tools/BuildAndTest.ps1，原始日志和报告按时间留存，失败日志也不得覆盖。
- 可运行 Tools/CollectProjectLogs.ps1 汇总既有项目历史，保留来源清单；不采集无关项目、账户配置、密钥或私人聊天。
- 同步更新本版本试玩包和工程包，保留替换前备份。仅仓库/文档整理且游戏内容未改时可重新打包已有试玩，明确未重建二进制、未执行新人工通关。最终告知启动文件、改动和日志位置。
- 当前工程协作入口为../README.md和../CONTRIBUTING.md；PNG统一在Assets/Art，真实分层源稿在../Figures/Source，不依赖已归档的旧Project或重复Figures PNG。
